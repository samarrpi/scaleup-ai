# Process Graph v3

The Process Graph is intentionally compact on the page and detailed on demand.

## UI principles

- Left-to-right topology keeps the diagram short for typical sequential processes.
- The diagram is rendered in a narrower page column so it does not dominate the application.
- Nodes show only essential identity information; the inspector carries detailed evidence and uncertainty.
- Relationship explanations are written in user-facing language.
- Relationship audit is collapsed by default to reduce visual density.
- The graph does not invent material flows or causal relationships.

## User explanation

The Graph tab explains:

1. what a node represents;
2. what an arrow represents;
3. what evidence means;
4. why the graph may be incomplete;
5. what the graph deliberately does not claim.

This keeps the interface usable for engineers who did not build the underlying data model.
